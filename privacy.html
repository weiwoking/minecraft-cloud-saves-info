Minecraft Cloud Saves 隐私权政策

适用范围：由拥有者本人使用的本地 restic、rclone 及 Minecraft 世界备份辅助脚本。此配置不提供面向公众的账户服务。

访问和用途

在用户通过 Google 官方登录页面授权后，rclone 使用 Google Drive API 管理本应用创建或经用户明确授权的备份数据。使用范围为 drive.file。工具使用文件标识、大小、校验信息及存储配额等信息，完成上传、下载、容量检查和历史恢复。

存储和保护

世界文件由 restic 在本地加密后写入用户自己的 Google Drive。用于自动访问的 OAuth 令牌和备份恢复密钥保存在本机用户的受限配置目录中。Google 账号密码不由本工具收集。用户应自行保护电脑、Google 账号和离线恢复密钥。

分享与处理

本配置不向工具开发者运营的服务器发送存档或凭据，不出售 Google 用户数据，不用于广告或 AI 模型训练。Google Drive 按其服务政策存储备份；首页及隐私说明由网页托管服务提供，该服务可能按自身政策处理常规访问日志。

用户控制

用户可停止本地脚本，或在 Google 账号的第三方连接设置中撤销授权。撤销访问不会自动删除已有备份。用户可自行决定何时删除本地及云端历史；本配置不自动购买存储空间。需要修改或停用此个人配置时，由拥有者通过本地设置及 Google Cloud 项目进行管理。

本政策所述 Google 用户数据的使用与转移遵守 Google API Services User Data Policy，包括 Limited Use 要求。
